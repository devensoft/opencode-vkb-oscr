# OSCR Agents

- **vibe-orchestrator** — Primary agent that orchestrates OpenSpec change requests through a 4-phase Vibe-Kanban workflow.
- **oscr-reviewer** — Hidden subagent that performs read-only code review on VKB worktree output.
- **oscr-verifier** — Hidden subagent that runs tests and type checks on VKB worktree output.
